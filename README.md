# odin-recipes

This is a project for learning HTML. I am currently following the odin project foundations curriculum. This project was built for https://www.theodinproject.com/lessons/foundations-recipes

## In this project I practiced the following things:

- unordered and ordered lists

- headings

- paragraphs

- images

- highlighting and empasising text (for structure, not styling)

- relative and absolute paths

- anchors

- comments

- HTML special characters

- Generally how to structure a page correctly

- Git (especially writing good commits)

I feel confident, that my HTML skills suffice, to move on to CSS and other aspects of web development
